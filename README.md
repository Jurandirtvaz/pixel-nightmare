# 🎮 Pixel Nightmare

> *Quando uma aula de Computação Gráfica vira um pesadelo pixelado.*

**Pixel Nightmare** é um jogo 2D top-down desenvolvido na **Godot Engine**, criado como projeto para a disciplina de Computação Gráfica na **UFAPE**. O jogo mistura humor, fantasia e o desespero universitário, transformando a universidade em um campo de batalha surreal.

---

## 📖 A História
O jogo se passa na **UFAPE**, onde o personagem principal, um estudante de BCC, está fazendo uma prova de **Computação Gráfica**.  
Durante a explicação do professor, o estudante acaba pegando no sono e desperta no estacionamento da UFAPE.

Nesse pesadelo, o jogador precisa enfrentar o **Boss: a Mão de Ícaro**, uma representação de uma das aulas do professor da disciplina.

Após derrotar o Boss, o personagem acorda e percebe que tudo não passou de um sonho.

---

## 🕹️ Como Jogar
O objetivo é simples: sobreviver e acordar.

- **Movimentação:** Use `WASD` para fugir dos ataques.
- **Combate Matemático:** Use o **Botão Esquerdo do Mouse** para lançar equações matemáticas contra o inimigo.
- **O Boss:** Enfrente a "Mão de Ícaro" em uma batalha de múltiplas fases com barra de vida dedicada.
- **Sobrevivência:** Gerencie suas vidas (HUD) e evite a temida tela de *Game Over*.
- **Vitória:** Derrote o boss, responda corretamente a pergunta para ver a cutscene final e descobrir o destino do estudante.

---

## 🛠️ Tecnologias
Este projeto foi construído do zero utilizando:

- **Engine:** Godot 4.4
- **Linguagem:** GDScript
- **Arte:** Pixel Art (com uso de placeholders durante o desenvolvimento)
- **Gráficos:** Shaders básicos, sistema de partículas e animações 2D.

---

## 🎓 Sobre o Projeto
Este jogo não é apenas sobre derrotar um boss, é a aplicação prática dos conceitos estudados na disciplina de **Computação Gráfica**, incluindo:

- Pipeline gráfico 2D.
- Manipulação de Sprites e Animações.
- Sistemas de Coordenadas e Transformações.
- Detecção de Colisão e Física.
- UI/UX (HUD e Menus).
